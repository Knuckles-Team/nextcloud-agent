# Provider workflow catalog

Load only the workflow relevant to the current request.

- [nextcloud-activity](../../nextcloud-activity/SKILL.md): Read the Nextcloud activity stream (who created, changed, shared or deleted what) for the whole account or one file, and read and dismiss notifications. Use when the agent must audit recent changes, confirm an action landed, or clear handled notifications. Do NOT use to change files or shares.
- [nextcloud-admin](../../nextcloud-admin/SKILL.md): Administer the Nextcloud workspace: read the connected account; list, read, create, update, disable, enable and delete accounts; list, create and delete groups and manage membership; list installed apps and enable or disable them. Use when the agent must onboard or offboard a team member, organize teams into groups, or check which apps are on. Requires an admin account. Do NOT use for contact cards (nextcloud-contacts).
- [nextcloud-calendar](../../nextcloud-calendar/SKILL.md): Run Nextcloud calendars over CalDAV: list calendars, create or delete a calendar, list events in a time range, read, create, update and delete events, with attendee invitations kept as drafts unless sending is explicitly requested. Use when the agent must schedule, reschedule or cancel a meeting or check availability. Do NOT use for to-dos (nextcloud-tasks) or contacts (nextcloud-contacts).
- [nextcloud-contacts](../../nextcloud-contacts/SKILL.md): Manage Nextcloud contacts over CardDAV: list address books, list contacts with names, emails, phones and organization, read, create, update and delete a contact. Use when the agent must look up or maintain customer, supplier or team contact details. Do NOT use for account administration (nextcloud-admin).
- [nextcloud-deck](../../nextcloud-deck/SKILL.md): Run Nextcloud Deck kanban boards: list, read, create and delete boards; list, create and delete stacks; create, read, update, move, assign and delete cards. Use when the agent must track work items through stages (to do, doing, done). Do NOT use for personal to-dos (nextcloud-tasks).
- [nextcloud-files](../../nextcloud-files/SKILL.md): Browse and manage Nextcloud files: list, download, upload text or binary (base64), create folders, move, copy, delete, read properties and quota, list and restore versions, search by name and type, and restore from the trash bin. Use when the agent must find, fetch, store or reorganize files, or roll a file back. Do NOT use for sharing (nextcloud-shares), publishing a produced asset (nextcloud-publish-asset) or graph ingestion (nextcloud-ingest).
- [nextcloud-ingest](../../nextcloud-ingest/SKILL.md): Federate Nextcloud records into the knowledge graph through the connector's declared sources: files and folders, shares, notes, Deck boards, Talk conversations, calendars and address books. Use when the agent must make Nextcloud data queryable in the graph or refresh it. Do NOT use to download or move a file (nextcloud-files) or to change shares (nextcloud-shares).
- [nextcloud-notes](../../nextcloud-notes/SKILL.md): Keep Nextcloud Notes: list notes by category, read, create, update and delete a note (markdown, stored as files in the Notes folder). Use when the agent must keep meeting notes, checklists or reference text the team can open in Notes. Do NOT use for collaborative office documents (nextcloud-office).
- [nextcloud-office](../../nextcloud-office/SKILL.md): Create office documents (docx, xlsx, pptx, odg) and collaborative markdown in Nextcloud and open browser editing sessions where everyone with access edits together in real time (Nextcloud Office on the built-in document server; Text for markdown). Use when the agent must start a document for people to work on. Do NOT use to upload a finished file (nextcloud-files).
- [nextcloud-publish-asset](../../nextcloud-publish-asset/SKILL.md): Publish a produced business asset (a photo, video, marketing graphic or document from the creative suite) to the team folder in Nextcloud and share it: copy it from the production archive into Team/<campaign>, grant the team group access once, and create an expiring public link for external use. Use when an asset is ready for the team or for a customer, partner or social post. Do NOT use to produce the asset (the creative suite skills), for machine delivery or a website/CDN URL (the object storage skills), or to post to social channels.
- [nextcloud-shares](../../nextcloud-shares/SKILL.md): Grant and audit access to Nextcloud files and folders: internal shares to a user, group or Talk conversation, and public links with password, expiry, label and note. Use when the agent must give someone access, produce a public link, audit who can see a path, or revoke access. Do NOT use to move or upload files (nextcloud-files).
- [nextcloud-talk](../../nextcloud-talk/SKILL.md): Use Nextcloud Talk: list, read, create, rename and delete conversations; list, add and remove participants; read chat history; post and delete messages. Use when the agent must message the team, keep a project channel, or read what was said. Do NOT use to email people or post to public social channels.
- [nextcloud-tasks](../../nextcloud-tasks/SKILL.md): Manage to-dos (VTODO) in Nextcloud task-capable calendars, which the Tasks app shows: list open or all tasks, create a task with due date and priority, update it, mark it complete or reopen it, delete it. Use when the agent must track personal or team to-dos. Do NOT use for kanban work items (nextcloud-deck) or meetings (nextcloud-calendar).
